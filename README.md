# WebLinks
-دليل الأدوات الاحترافية
منصة عربية تجمع مجموعة من الأدوات والمواقع المفيدة في مجالات التصميم، والمونتاج والفيديو، والبرمجة وتطوير الويب، والتدريب وتعلّم اللغات.

🌐 افتح الموقع مباشرة : https://web-links-live.netlify.app/

✨ المميزات
- تصفح الأدوات ضمن أقسام واضحة: التصميم، والمونتاج والفيديو، والبرمجة والمواقع، والتدريب واللغات.
- البحث عن الأدوات باستخدام الاسم أو الوصف.
- تصفية الأدوات حسب القسم.
- ترتيب النتائج حسب التقييم أو الاسم أو السعر، مع إظهار الخيارات المجانية أولاً.
- بطاقات تعرض نبذة عن كل أداة، والمنصات المدعومة، ونوع السعر، والتقييمات، ورابط الموقع الرسمي.
- واجهة عربية باتجاه كتابة من اليمين إلى اليسار.
- تصميم متجاوب مع أحجام الشاشات المختلفة.
🛠️ التقنيات المستخدمة
- HTML5 لبناء هيكل الصفحات.
- CSS3 للتصميم والتنسيق والتجاوب.
- JavaScript (Vanilla JS) للبحث والتصفية والترتيب وإنشاء بطاقات الأدوات.
- Google Fonts لخطّي Tajawal وSpace Grotesk.
🚀 تشغيل المشروع محلياً
لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم خلفي.
1. نزّل ملفات المشروع أو انسخ المستودع.
2. احتفظ بالملفات index.html و`style.css` و`main.js` في المجلد نفسه.
3. افتح index.html في المتصفح.
يمكنك أيضاً فتح المجلد باستخدام Visual Studio Code وتشغيله عبر إضافة Live Server.
